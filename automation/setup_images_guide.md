# הכנת תמונות הייחוס לסוכן שיקלולט

## מה זה?

הסוכן מזהה אלמנטים בממשק שיקלולט על פי **תמונות ייחוס** (screenshots של כפתורים ותפריטים).
עליך ליצור תמונות אלה פעם אחת מהמחשב שלך.

## איך ליצור את התמונות?

1. פתח את שיקלולט על המחשב שלך
2. צלם את כל אחד מהאלמנטים הבאים בכלי Snipping Tool של Windows
3. שמור אותן בתיקייה `images/` בתוך תיקיית ה-automation

## רשימת תמונות נדרשות:

| שם קובץ | מה לצלם |
|---------|---------|
| `images/year_dropdown.png` | הכפתור / השדה לבחירת שנה |
| `images/month_dropdown.png` | הכפתור / התפריט לבחירת חודש |
| `images/month_1.png` עד `images/month_12.png` | כל אחד מהחודשים כפי שמופיע בתפריט |
| `images/all_employees_btn.png` | הכפתור / האפשרות "כל העובדים" |
| `images/employee_search_field.png` | שדה החיפוש לפי עובד |
| `images/export_pdf_btn.png` | כפתור ייצוא / הדפסה לPDF |
| `images/save_dialog.png` | חלון שמירת הקובץ (אם קיים) |

## טיפים:

- צלם **רק** את הכפתור / השדה, ללא רקע מיותר
- ודא שהרזולוציה של המסך זהה בין הצילום להרצה
- אם הממשק של שיקלולט משתנה בין גרסאות, עדכן את התמונות

## אלטרנטיבה — מיקומים קבועים

אם שיקלולט תמיד פתוח באותו גודל מסך, אפשר לוותר על תמונות ולהשתמש
ב**קואורדינטות קבועות** (x,y) בקוד. עדכן את השורות המסומנות ב-`# ← CUSTOMIZE THIS`.

## להרצת הסוכן:

```bash
cd automation
pip install -r requirements.txt
copy .env.agent.example .env.agent
# ערוך את .env.agent עם הערכים הנכונים
python shiklolet_agent.py
```
